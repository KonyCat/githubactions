# TechShop - Landing Page de E-commerce

Una landing page moderna y responsive para una tienda de tecnología online.

## 🚀 Características

- **Diseño Responsive**: Adaptable a todos los dispositivos (móvil, tablet, desktop)
- **Hero Section**: Sección principal con ofertas destacadas y estadísticas
- **Catálogo de Productos**: Grid de productos con filtros por categoría
- **Carrito de Compras**: Sistema de carrito con persistencia en localStorage
- **Sección de Ofertas**: Banner promocional con countdown timer
- **Testimonios**: Sección de reseñas de clientes
- **Newsletter**: Formulario de suscripción
- **Formulario de Contacto**: Para consultas de clientes
- **Footer Completo**: Con enlaces rápidos y redes sociales

## 💻 Instalación y Uso

1. Clona el repositorio:
```bash
git clone https://github.com/KonyCat/githubactions.git
```

2. Abre el archivo `index.html` en tu navegador favorito

3. ¡Listo! La landing page estará funcionando

## 🎨 Secciones de la Landing Page

1. **Header/Navegación**: Menú fijo con logo, enlaces y carrito
2. **Hero**: Sección principal con CTA y estadísticas
3. **Marcas**: Logos de marcas asociadas
4. **Productos**: Grid de productos destacados con filtros
5. **Beneficios**: Características del servicio (envío gratis, pago seguro, etc.)
6. **Oferta Especial**: Banner con countdown
7. **Testimonios**: Opiniones de clientes
8. **Newsletter**: Suscripción al boletín
9. **Contacto**: Información y formulario de contacto
10. **Footer**: Enlaces y redes sociales

## 📱 Responsive Design

La landing page está optimizada para:
- Móviles (< 480px)
- Tablets (480px - 768px)
- Laptops (768px - 1024px)
- Desktops (> 1024px)

## ⚡ Funcionalidades JavaScript

- Menú móvil animado
- Carrito de compras con localStorage
- Filtrado de productos por categoría
- Contador regresivo para ofertas
- Smooth scroll para navegación
- Botón "Volver arriba"
- Notificaciones toast
- Formularios interactivos
